==================================================
1. PRODUCT CONCEPT
==================================================

CityPulse is an AI-powered urban intelligence platform.

Citizens can report problems such as:

- potholes
- road damage
- flooding
- garbage overflow
- traffic problems
- broken streetlights
- pollution
- infrastructure problems

CityPulse analyzes the report, sends it through a verification workflow, calculates risk, and helps administrators prioritize urban problems.

The key idea is:

Citizen Report
        ↓
AI Analysis
        ↓
Verification
        ↓
Risk Engine
        ↓
Prediction
        ↓
Admin Action
        ↓
Resolution

IMPORTANT PRODUCT PRINCIPLE:

Citizen reports must NOT automatically become official truth.

Every report starts as:

PENDING_VERIFICATION

Only VERIFIED reports should influence the official risk score.

AI is a decision-support system.

AI must NOT:
- declare a real emergency
- contact authorities automatically
- punish users
- make irreversible decisions
- automatically ban users

Human administrators make high-impact decisions.

7. DATABASE SCHEMA
==================================================

Create Supabase SQL migrations.

TABLE: profiles

Fields:

id UUID primary key references auth.users(id)
full_name TEXT
email TEXT
role TEXT CHECK(role IN ('CITIZEN','ADMIN'))
avatar_url TEXT
created_at TIMESTAMPTZ
updated_at TIMESTAMPTZ

TABLE: reports

id UUID primary key
user_id UUID references profiles(id)
category TEXT
title TEXT
description TEXT
image_url TEXT
latitude DOUBLE PRECISION
longitude DOUBLE PRECISION
location_name TEXT
severity TEXT CHECK(severity IN ('LOW','MEDIUM','HIGH'))
status TEXT CHECK(
status IN (
'PENDING_VERIFICATION',
'VERIFIED',
'REJECTED',
'ASSIGNED',
'IN_PROGRESS',
'RESOLVED'
))
ai_confidence DOUBLE PRECISION
ai_category TEXT
ai_summary TEXT
suspicious BOOLEAN DEFAULT false
duplicate_of UUID
evidence_count INTEGER DEFAULT 1
created_at TIMESTAMPTZ
updated_at TIMESTAMPTZ

TABLE: risk_scores

id UUID primary key
location_name TEXT
latitude DOUBLE PRECISION
longitude DOUBLE PRECISION
traffic_risk INTEGER
flood_risk INTEGER
infrastructure_risk INTEGER
pollution_risk INTEGER
verified_report_risk INTEGER
overall_risk INTEGER
risk_level TEXT
calculated_at TIMESTAMPTZ

TABLE: predictions

id UUID primary key
location_name TEXT
prediction_type TEXT
probability DOUBLE PRECISION
expected_start TIMESTAMPTZ
expected_end TIMESTAMPTZ
contributing_factors JSONB
recommendation TEXT
created_at TIMESTAMPTZ

TABLE: admin_actions

id UUID primary key
admin_id UUID references profiles(id)
report_id UUID references reports(id)
action TEXT
notes TEXT
created_at TIMESTAMPTZ

TABLE: alerts

id UUID primary key
title TEXT
message TEXT
severity TEXT
location_name TEXT
related_report_id UUID
read BOOLEAN DEFAULT false
created_at TIMESTAMPTZ

Create useful indexes for:
- reports.status
- reports.category
- reports.created_at
- reports.user_id
- reports.latitude
- reports.longitude
- risk_scores.risk_level
- risk_scores.location_name
